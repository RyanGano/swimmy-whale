# Swimmy Jail

An underwater, Jonah-inspired Flappy Bird-style arcade game. Guide a great fish through coral reefs, kelp forests, and ancient ruins.

## Play locally

Open `index.html` in a modern browser, or serve the folder with any static-file server. Use spacebar, click, or tap to swim. The game uses the Web Share API after a run, falling back to copying the score where device sharing is unavailable.

## GitHub Pages

The site is designed for deployment directly from the repository root with GitHub Pages.
